# ForgeaX 作品集整合设计

## 目标

将 ForgeaX Studio 作为独立代表项目加入网站和作品集 PDF，准确体现“ForgeaX 是团队项目，游戏音频模块由胡锦霖独立负责”的职责边界，并提供可验证的团队开源仓库链接。

## 已确认边界

- ForgeaX Studio 属于团队项目，不写成个人项目，也不关联腾讯名称。
- 胡锦霖独立负责整个游戏音频模块。
- 个人工作覆盖需求拆解、Prompt / Agent 工作流设计、工具代码实现、测试及迭代。
- 现有项目全部保留；新增 ForgeaX 时不删除或替换 `FULL MOON` 等作品。
- 对外链接统一指向团队仓库：<https://github.com/ForgeaX-Games/forgeax-studio>。
- 链接文案使用“查看团队开源仓库”，不使用“我的 GitHub 项目”。

## 网站设计

### 位置与顺序

在“代表项目”区域中，将 ForgeaX 卡片放在《Desserted! 爆牌甜心》之后、FPS 原型之前。该顺序先展示完整的个人游戏音频项目，再展示团队项目中的模块所有权，随后展示 Wwise 技术练习。

### 卡片结构

- 项目类型：`Team Project · Game Audio Module Owner`
- 标题：`ForgeaX Studio｜AI 游戏音频模块`
- 描述：

  > 在 ForgeaX Studio 团队项目中，独立负责游戏音频模块从需求拆解、Prompt / Agent 工作流设计、工具代码实现到测试迭代的完整流程；搭建覆盖 BGM 结构化检索、SFX 方案解析、音频事件扫描、绑定草稿、应用与验证的工具链，使游戏音频需求能够由 AI Agent 执行并在项目中落地。

- 标签：`AI Agent`、`Game Audio System`、`Audio Tools`、`Workflow Design`
- 操作：`查看团队开源仓库`

### 交互与资产

- 使用 ForgeaX 官方仓库或官网中的真实 Studio 界面截图，不制作虚假界面或占位图。
- ForgeaX 卡片为外部项目链接，不伪装成站内视频播放器。
- 点击卡片图片或“查看团队开源仓库”后，在新标签页打开团队仓库。
- 外链包含 `target="_blank"` 和 `rel="noopener noreferrer"`。
- 保持现有卡片尺寸、字体、边框、悬停效果和响应式网格不变。

## PDF 设计

### 页面结构

- 保留现有 10 页的全部内容。
- 在《Desserted! 爆牌甜心》之后新增 ForgeaX 页面，PDF 总页数调整为 11 页。
- ForgeaX 成为 `PROJECT 02`；原 `PROJECT 02–07` 顺延为 `PROJECT 03–08`。
- 所有页面的 `01 / 10` 至 `10 / 10` 更新为对应的 `01 / 11` 至 `11 / 11`。

### 视觉一致性

新增页严格复用现有项目页视觉系统：

- 画布保持 1440 × 810 横版比例。
- 黑色背景、白色主标题、灰色正文、青绿色强调色保持一致。
- 顶部使用细分隔线、左侧章节编号、右侧 `HU JINLIN · AUDIO PORTFOLIO`。
- 左侧放项目编号、标题、职责、描述、标签和仓库入口；右侧放 ForgeaX 官方 Studio 截图。
- 右侧截图沿用现有深色卡片容器、圆角、内边距和底部青绿色短线。
- 底部继续使用 `SELECTED WORK / AUDIO PORTFOLIO` 和统一页码。
- 不新增与现有 PDF 不一致的渐变、字体、图标风格或装饰系统。

### 页面文案

- 页面章节：`04 / AI 游戏音频模块`
- 项目编号：`PROJECT 02`
- 标题：`ForgeaX Studio`
- 副标题：`AI Agent 与游戏音频工作流`
- 描述：

  > 在团队项目中独立负责游戏音频模块，完成需求拆解、Prompt / Agent 工作流设计、工具代码实现、测试及迭代；搭建覆盖 BGM 结构化检索、SFX 方案解析、音频事件扫描、绑定草稿、应用与验证的完整工具链。

- 标签：`AI Agent`、`Game Audio System`、`Audio Tools`、`Workflow Design`
- 仓库入口：可点击文字 `查看团队开源仓库`、可读短链接和二维码均指向同一 GitHub 地址。

## 测试与验收

### 网站

- ForgeaX 卡片位于 Desserted 之后、FPS 之前。
- 页面仍有 5 个可点击播放的视频项目，ForgeaX 使用独立外链，不改变视频加载逻辑。
- ForgeaX 官方图片正常加载，桌面和移动端均不裁切关键信息。
- 卡片与按钮均能正确打开团队仓库，且没有把项目表述为个人仓库。
- 现有视频、音频、文档下载和简历下载功能保持正常。

### PDF

- 最终文件为 11 页，原有内容全部保留。
- 每一页总页数、当前页码、项目编号和章节编号连续且正确。
- ForgeaX 新增页与现有项目页在字体、颜色、间距、截图容器和页眉页脚上保持一致。
- GitHub 文字链接与二维码均可访问同一团队仓库。
- 全部 11 页完成渲染检查，无文字裁切、重叠、缺字、图片变形或页码残留。

## 不在本次范围

- 不把整个 ForgeaX 项目标记为个人独立开发。
- 不新增单独的 ForgeaX 详情页、技术博客或架构长文。
- 未经确认不推送网站改动，也不覆盖用户提供的原始 PDF。
