# 秋招作品集文案设计

## 目标

保留现有视觉、布局、媒体与交互，只改页面文字，使作品集与当前秋招简历一致，并让招聘官快速看到岗位方向、个人职责和可验证结果。

## 文案原则

- 结论和结果先行，减少“深度、完整、精细、力求”等自评词。
- 经历与当前简历一致：腾讯光子、太合音乐—GVO、《Desserted! 爆牌甜心》和“混出名堂”。
- 个人练习明确标注“个人练习、非官方项目”。
- AIGC明确人工与AI的职责边界，不作为首要卖点。
- 保留现有页面结构、下载文件、媒体与卡片顺序，只改可见文字和无障碍文字。
- 旧简历文件保留并明确标注为“实习版”，不将其冒充当前秋招简历。

## 页面内容

- 首屏：岗位方向、工作方法、三项证据标签。
- 关于：教育背景、腾讯光子、太合音乐、独立游戏和秋招状态。
- 代表项目：每张卡说明项目性质、个人动作和结果。
- 音乐制作与混音：准确描述AIGC流程、已发行作品职责和混音能力。
- 联系：改为2027届秋招口径。

## 验收标准

- 页面不再出现旧公司“成都星线传媒”和“实习岗位”求职口径。
- 《Desserted! 爆牌甜心》名称统一。
- 已发行音乐不再使用“独立负责”的过度表述。
- 三角洲与雨之城明确为个人非官方练习。
- 原有五个视频、三个音频、两个设计文档及联系方式功能保持不变。
- 《Desserted! 爆牌甜心》和《雨之城》只展示有内容证据的工具标签；已发行音乐明确当前试听曲目。
